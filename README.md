## Projeto em destaque

### Aluno Online API

API REST para gerenciamento acadêmico desenvolvida com Java e Spring Boot, permitindo o gerenciamento de alunos, professores, disciplinas e matrículas.

O projeto conta com autenticação e autorização utilizando Spring Security e JWT, documentação interativa com Swagger/OpenAPI, persistência de dados com PostgreSQL e ambiente de banco de dados com Docker Compose.

Entre as principais funcionalidades estão cadastro e gerenciamento de alunos, professores e disciplinas, matrícula de alunos, atualização de notas, trancamento de matrícula e emissão de histórico acadêmico consolidado.
